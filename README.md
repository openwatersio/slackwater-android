# Slackwater for Android

Native Android app for offline tide and current predictions.

The app is in development planning. The [implementation plan](docs/superpowers/plans/2026-11-05-android-development.md) describes the delivery stages, dependencies, proposed architecture, and verification work. The [iOS parity ledger](docs/ios-parity.md) maps requirements to the Slackwater iOS product contracts at PR #900 and records Android platform adaptations.

Implementation is tracked in the [repository issues](https://github.com/openwatersio/slackwater-android/issues). The repository does not yet contain a buildable Android app.
